 # ProcureMate

Multi-agent AI system that automates enterprise procurement using intelligent agents.

## Technologies
- AutoGen, CrewAI, LangChain
- GPT-4 / Gemini
- Python (Backend)
- React.js (Frontend)
- Firebase / MongoDB
- Google API, Scraping tools

## Folder Structure
- `agents/` – All agent implementations
- `backend/` – Python backend services
- `frontend/` – React frontend
- `data/` – Sample or scraped data
- `utils/` – Shared utilities
- `docs/` – Reports, diagrams, exposes
